# Kit de instalación local

Scripts para descargar, instalar y abrir God's Eye View – La Guajira en tu
computador. La explicación completa está en
[GUIA-TRABAJO-LOCAL.md](../GUIA-TRABAJO-LOCAL.md).

| Sistema     | Preparar (descarga, instala y abre)    | Abrir después                         |
| ----------- | -------------------------------------- | ------------------------------------- |
| Windows     | doble clic en `1-preparar-windows.bat` | doble clic en `2-iniciar-windows.bat` |
| macOS/Linux | `bash preparar-mac-linux.sh`           | `bash iniciar-mac-linux.sh`           |

Si ejecutas los scripts desde esta carpeta dentro del proyecto, trabajan sobre
este mismo proyecto. Si los ejecutas desde el kit descargado, clonan el
proyecto en `proyectos/God-s-Eye-View-La-Guajira`, dentro de tu carpeta de
usuario (cámbiala con `-Destino` en Windows o `--destino` en macOS/Linux).
